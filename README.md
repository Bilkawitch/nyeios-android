# NyEIOS

Быстрый, легкий и современный неофициальный Android-клиент для студентов некоего универа. Разработан на Jetpack Compose и Material 3.

## Зачем это приложение?

Официальный веб-портал перегружен тяжелыми скриптами и табличной версткой, из-за чего на смартфонах страницы открываются медленно, а при плохом интернете доступ к расписанию часто теряется.

**NyEIOS** решает эти проблемы:
- **Мгновенная работа**: парсит только полезные данные за доли секунды (~0.1–0.3 с).
- **100% Оффлайн-доступ (SWR)**: расписание, лента и успеваемость кэшируются локально — приложение сразу открывается даже в подвале корпуса или при отсутствии связи.
- **Эргономичный Dark UI**: стильный интерфейс Obsidian Dark, созданный специально для комфортного ежедневного использования.
- **Безопасность**: учетные данные сессии шифруются через аппаратный **Android Keystore** (`EncryptedSharedPreferences`).

## Что умеет NyEIOS?

### Расписание занятий
- Удобная навигация по неделям и дням («Пн»–«Сб»).
- Индикатор текущей пары **«Сейчас идёт»** с таймером до конца занятия.
- Цветовая дифференциация типов пар (лекция, практика, лабораторная, зачет/экзамен).

### Поэтажная indoor-навигация (Главный корпус)
- Интерактивная векторная карта 3 и 4 этажей с поддержкой масштабирования и перемещения (1, 2 этажи и новый корпус в разработке).
- Поиск кабинетов и точная привязка дверей.
- **Навигация от пары к паре**: автоматическое построение пешеходного маршрута от предыдущей аудитории к следующей.
- **Межэтажные маршруты**: расчет кратчайшего пути с автоматическим выбором ближайшей лестницы (Западная, Центральная, Восточная) и визуализацией перехода между этажами.

### Живая лента
- Публикации и задания от преподавателей и кафедр с фильтрацией по учебным группам.
- Скачивание и открытие прикрепленных учебных файлов (`.pdf`, `.docx`, `.xlsx`, `.zip`) прямо из приложения.

### Успеваемость (БРС)
- Электронная зачетная книжка по всем семестрам обучения.
- Промежуточный контроль (КТ1, КТ2), семестровый рейтинг, экзаменационные баллы и итоговые оценки.

## Сборка из исходного кода

### Требования
- **JDK 17+** (рекомендуется JDK 17 или JDK 21)
- **Android SDK Platform 34** (Build-Tools 34.0.0+)
- **Android Studio** (Koala / Ladybug или новее) либо командная строка Gradle

### Команды сборки
```bash
# Клонирование репозитория
git clone https://github.com/Bilkawitch/nyeios-android.git
cd nyeios-android

# Сборка релизного APK (будет создан в app/build/outputs/apk/release/)
./gradlew assembleRelease

# Сборка отладочного APK
./gradlew assembleDebug

# Запуск полного комплекта юнит-тестов
./gradlew testDebugUnitTest
```
