# NyEIOS 📅⚡ (Android)

Нативный легковесный Android-клиент для просмотра расписания портала ЭИОС ГСГУ (Государственный социально-гуманитарный университет, г. Коломна).

## ⚡ Зачем это сделано?

Официальный сайт ЭИОС (`eios.gukolomna.ru`) на смартфонах работает медленно, подгружая более 7.5 МБ тяжелого HTML, тысячи записей сотрудников и внешние ресурсы. 

**NyEIOS** решает эту проблему:
- Загружает **только данные расписания** за доли секунды (~0.1–0.3 с).
- Поддерживает **оффлайн-режим**: мгновенный старт приложения из локального кэша даже без интернета.
- Имеет стильный и плавный **Dark Obsidian UI** (Material 3 + Jetpack Compose) с цветовым кодированием занятий и отслеживанием текущей пары в реальном времени.
- Защищённая авторизация: учетные данные шифруются аппаратным ключом **Android Keystore** (`EncryptedSharedPreferences`).

## ✨ Возможности

- 🎨 **Современный интерфейс (Dark Obsidian)**: контрастная темная тема с акцентными плашками и карточками.
- 📆 **Навигация по неделям и дням**: переключение между неделями (`◀`, `📅 Текущая`, `▶`), горизонтальные чипы дней недели (`Пн`–`Сб`) с индикатором «Сегодня».
- 🔴 **Живой индикатор пары («Сейчас идёт»)**: карточка текущего занятия мягко подсвечивается изумрудным контуром и бейджем с расчетом времени.
- 🏷️ **Цветовое кодирование дисциплин**:
  - 📘 **Лекция** — Sapphire Blue
  - 📗 **Семинар / Практика** — Emerald Green
  - 📙 **Лабораторная** — Amber Bronze
  - 📕 **Экзамен / Зачёт / Контрольная** — Crimson Red
- 🔐 **Безопасный вход**: удобная шторка авторизации Битрикс без открытого хранения паролей.
- 🔄 **Pull-to-refresh**: обновление расписания в один жест.

## 📦 Установка

Готовый APK-файл находится в корне проекта:
- `NyEIOS-debug.apk` (или в `app/build/outputs/apk/debug/app-debug.apk`).

Скопируйте его на Android-смартфон и установите (разрешив установку из неизвестных источников).

---

## 🛠 Сборка из исходного кода

Требования:
- JDK 17+ (или JDK 22)
- Android SDK (API 34)

Сборка отладочной версии:
```bash
./gradlew assembleDebug
```

Запуск юнит-тестов:
```bash
./gradlew testDebugUnitTest
```
