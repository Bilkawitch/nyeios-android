# NyEIOS 📱⚡ (Android)

Нативный легковесный Android-клиент для студентов ГОУ ВО МО «ГСГУ» (Государственный социально-гуманитарный университет, г. Коломна). Включает расписание занятий, живую ленту объявлений и успеваемость по балльно-рейтинговой системе (БРС) с официального портала **eios.gukolomna.ru**.

## ⚡ Зачем это сделано?

Официальный сайт ЭИОС (`eios.gukolomna.ru`) на смартфонах работает крайне медленно, отдавая более 7.5 МБ тяжелого монолитного HTML на каждый запрос с сотнями избыточных скриптов. 

**NyEIOS** решает эту проблему:
- Загружает **только полезные данные** за доли секунды (~0.1–0.3 с).
- Поддерживает **100% оффлайн-режим (SWR)**: мгновенный старт приложения из локального кэша даже без подключения к интернету.
- Имеет стильный и эргономичный **Dark Obsidian UI** (Material 3 + Jetpack Compose) с плавной навигацией по разделам.
- Защищённая авторизация: учетные данные шифруются аппаратным ключом **Android Keystore** (`EncryptedSharedPreferences`).

## ✨ Возможности

### 📅 Расписание занятий
- 📆 **Навигация по неделям и дням**: переключение недель (`◀`, `📅 Текущая`, `▶`), горизонтальные чипы дней недели (`Пн`–`Сб`) с индикатором «Сегодня».
- 🔴 **Живой индикатор пары («Сейчас идёт»)**: карточка текущего занятия подсвечивается мягким изумрудным контуром и бейджем с расчетом времени.
- 🏷️ **Цветовое кодирование дисциплин**:
  - 📘 **Лекция** — Sapphire Blue
  - 📗 **Семинар / Практика** — Emerald Green
  - 📙 **Лабораторная** — Amber Bronze
  - 📕 **Экзамен / Зачёт / Контрольная** — Crimson Red

### 📢 Живая лента
- Посты и важные объявления от преподавателей и деканата с датами и указанием целевых групп (`→ 23ан-о-41`).
- Монограммы-аватары преподавателей для быстрого визуального считывания.
- 📎 **Прикрепленные файлы**: просмотр и открытие вложений (`.pdf`, `.docx`, `.xlsx`, `.zip`) прямо из ленты.

### 🎓 Успеваемость и БРС
- 📊 **Семестровые ведомости**: переключение между семестрами обучения (1–10 семестры) с автоматическим определением текущего семестра.
- 📈 **Сводные показатели**: общее количество дисциплин, число экзаменов и зачетов за выбранный семестр.
- 🏆 **Детализация баллов БРС**: текущий контроль (КТ1, КТ2), семестровый рейтинг, экзаменационный балл, итоговый рейтинг, зачетные единицы (ЗЕТ) и академические часы.
- Цветовая индикация формы контроля (Экзамен, Диф. зачет, Зачет) и полученных оценок (*Отлично*, *Хорошо*, *Зачтено*).

### 🛠 Архитектура и удобство
- 🧭 **Нижняя панель навигации (NavigationBar)**: быстрое переключение между Расписанием, Лентой и Успеваемостью в одно касание.
- 🔐 **Безопасный вход**: удобная шторка авторизации без открытого хранения паролей.
- 🔄 **Pull-to-refresh & кнопка обновления**: ручная и фоновая синхронизация данных с индикацией процесса.

## 📦 Установка

Готовый APK-файл находится в корне проекта:
- `NyEIOS-debug.apk` (или в `app/build/outputs/apk/debug/app-debug.apk`).

Скопируйте его на Android-смартфон и установите (разрешив установку из неизвестных источников).

---

## 🛠 Сборка из исходного кода

Требования:
- JDK 17+ (или JDK 22)
- Android SDK (API 34)

Сборка отладочной версии:
```bash
./gradlew assembleDebug
```

Запуск юнит-тестов:
```bash
./gradlew testDebugUnitTest
```
